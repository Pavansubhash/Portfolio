# Pavan Subhash Parupudi — Portfolio v2

A fresh, responsive portfolio experience built with React, Vite, Framer Motion and Lucide icons.

## Run locally

```bash
cd portfolio-v2
npm install
npm run dev
```

Create a production build with `npm run build`.

## Experience highlights
- Editorial dark UI with lime accents, responsive navigation and custom CSS illustrations.
- Framer Motion page entrances, viewport reveals, hover micro-interactions, expandable experience cards and animated hero artwork.
- Sections for profile, impact metrics, work experience, selected engineering themes, skills, education, certifications and contact.
- Copy-email interaction, keyboard focus states, reduced-motion support and mobile navigation.
- No external API keys or backend required.

## Before publishing
- Update the LinkedIn URL in `src/App.jsx` to the exact profile URL.
- Add a real resume PDF and replace the resume-request email link if desired.
- Review all metrics and experience statements before public release.
- Run `npm run build` before deployment.

## Deploy
Deploy this directory as a Vite static site on Vercel, Netlify, or GitHub Pages. Set the project root to `portfolio-v2`, build command to `npm run build`, and output directory to `dist`.
